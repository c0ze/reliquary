# Reliquary

A personal **memory server for AIs** — [Mem0](https://github.com/mem0ai/mem0) +
Qdrant behind the **Model Context Protocol (MCP)**, so any Claude or ChatGPT
session can search and store your long-term memories.

> 🚧 Scaffolding in progress — the service code, Docker setup, and full
> documentation land via the first pull request.
